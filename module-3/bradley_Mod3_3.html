5 Things I've Learned Since the Course Started

  1. HTML and CSS live in separate files for a reason, and the browser will not forgive a wrong guess.
  2. The box model is not a suggestion. Margins and padding will fight you until you actually understand them.
  3. GitHub Pages does not care how good your code looks if you forget to push it.
  4. A missing closing tag can quietly break something four elements later.
  5. The W3C validator has strong opinions, and it will share every single one of them.
